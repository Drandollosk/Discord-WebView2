# Diskord — отдельное приложение для Discord Web

Открывает настоящий официальный веб-клиент Discord (`https://discord.com/app`)
в собственном окне со встроенным WebView (Microsoft Edge WebView2) —
без вкладок, адресной строки и вообще без обычного браузера на экране.

## Установка

Дважды кликните **`Установить Discord.bat`**.

Откроется обычное окно консоли — оно ставит зависимости и собирает
приложение сразу в:

```
%LOCALAPPDATA%\Discord_v2\Discord\Discord.exe
```

(обычно это `C:\Users\<вы>\AppData\Local\Discord_v2\Discord\Discord.exe`)
и кладёт ярлык **Discord** на рабочий стол, который указывает туда.
Занимает ~1-2 минуты в первый раз. В конце — «Done!», нажмите любую
клавишу, чтобы закрыть окно.

Сборка — это папка (`Discord\` со всеми файлами рядом с `Discord.exe`),
а не один самораспаковывающийся файл: так приложение запускается за
секунду-другую вместо 3-4 секунд на распаковку рантайма при каждом
старте (этим страдал более ранний `--onefile`-вариант).

**Эта папка проекта (`diskord` с исходным кодом) нужна только для сборки.**
После установки всё, что нужно приложению для работы — сам `Discord.exe`,
его лог и кеш WebView2 — лежит в `Discord_v2` внутри `AppData\Local`. Всю
эту папку `diskord` можно удалить, Discord продолжит работать из
`AppData\Local\Discord_v2` (ярлык на рабочем столе не сломается).

Если позже захотите пересобрать (например, я пришлю новую версию
`discord_app.py`) — просто скопируйте новый файл в эту папку и запустите
`Установить Discord.bat` заново.

### Что для этого нужно на компьютере

- Windows 10/11.
- Python 3.9+ ([python.org](https://www.python.org/downloads/), при
  установке отметьте "Add python.exe to PATH"). Если Python не найден,
  скрипт сразу об этом скажет.
- Microsoft Edge WebView2 Runtime — почти наверняка уже стоит (входит в
  Windows 11 и ставится вместе с обновлениями Edge на Windows 10).

## Полное удаление приложения

Раз всё лежит в одной папке `AppData\Local\Discord_v2` — для полного
удаления достаточно:

1. удалить ярлык **Discord** с рабочего стола;
2. удалить папку `%LOCALAPPDATA%\Discord_v2` целиком (можно вставить этот
   путь прямо в адресную строку Проводника).

## Очистка папки проекта от старых файлов

Если в папке остались файлы от более ранних версий этого проекта —
дважды кликните **`Очистить папку.vbs`** (без окон, только одно
сообщение "Готово" в конце). Она не трогает `discord_app.py`,
`requirements.txt`, `icons\icon.ico`, `README.md`,
`Установить Discord.bat`, `create_shortcut.ps1`.

## Файлы в проекте

- `discord_app.py` — код приложения.
- `requirements.txt` — зависимости (`pywebview`, `pythonnet`).
- `Установить Discord.bat` — установка/сборка в `AppData\Local\Discord_v2`
  + ярлык на рабочем столе.
- `create_shortcut.ps1` — вызывается из .bat, создаёт ярлык (правильно
  определяет папку Desktop, даже если её переносит OneDrive; иконка
  берётся прямо из готового exe, а не из файла проекта).
- `Очистить папку.vbs` — разовая уборка файлов от старых версий проекта.
- `icons/icon.ico` — иконка, встраивается в exe при сборке.

## Если ярлык на рабочем столе не появился

`create_shortcut.ps1` определяет настоящий путь к рабочему столу через
Windows API (учитывает перенос папки OneDrive'ом) и .bat печатает точный
путь к ярлыку в конце. Если создать всё равно не получилось — `Discord.exe`
это никак не портит, просто запускайте его напрямую из
`%LOCALAPPDATA%\Discord_v2\Discord\Discord.exe` (можно закрепить на панели
задач).

## Если иконка приложения не обновилась после пересборки

Windows кеширует иконки exe-файлов и ярлыков, поэтому после пересборки с
новым `icons\icon.ico` можно продолжать видеть старую картинку, пока кеш
не обновится. `.bat`-скрипт сам пытается сбросить кеш иконок
(`ie4uinit.exe -show`) в конце установки. Если не помогло — самый надёжный
способ форсировать обновление: перезапустить `explorer.exe` (Диспетчер
задач → найти "Проводник" → Перезапустить) или перезагрузить компьютер.

## Если окно Discord открылось, но оно белое/пустое

1. Проверьте `diskord_error.log` в
   `%LOCALAPPDATA%\Discord_v2\Discord` (рядом с `Discord.exe`) — там
   пишется, что именно произошло (открылась ли страница, какие были
   ошибки JS).
2. Чаще всего причина — не установлен WebView2 Runtime:
   https://developer.microsoft.com/microsoft-edge/webview2/
3. Можно кликнуть правой кнопкой по окну → **Inspect Element** —
   откроются DevTools, во вкладке Console будет видно, что не грузится.

## Почему именно так

Discord.com — тяжёлое современное веб-приложение, поэтому нужен
Chromium-движок (WebView2), а не старый `WebBrowser`/IE-контрол. `pywebview`
на Windows как раз использует WebView2 под капотом — это тот же движок,
что и в официальном десктоп-клиенте Discord (тот тоже обёртка вокруг
веб-версии, только на Electron).
