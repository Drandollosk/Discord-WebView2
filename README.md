# Diskord — отдельное приложение для Discord Web

Открывает настоящий официальный веб-клиент Discord (`https://discord.com/app`)
в собственном окне со встроенным WebView (Microsoft Edge WebView2) —
без вкладок, адресной строки и вообще без обычного браузера на экране.

## Установка

Дважды кликните **`Установить Discord.bat`**.

Откроется обычное окно консоли — оно ставит зависимости и собирает
приложение сразу в:

```
%LOCALAPPDATA%\Discord_v2\Discord\Discord.exe
```

(обычно это `C:\Users\<вы>\AppData\Local\Discord_v2\Discord\Discord.exe`)
и кладёт ярлык **Discord** на рабочий стол, который указывает туда.
Занимает ~1-2 минуты в первый раз. В конце — «Done!», нажмите любую
клавишу, чтобы закрыть окно.

Сборка — это папка (`Discord\` со всеми файлами рядом с `Discord.exe`),
а не один самораспаковывающийся файл: так приложение запускается за
секунду-другую вместо 3-4 секунд на распаковку рантайма при каждом
старте (этим страдал более ранний `--onefile`-вариант).

**Эта папка проекта (`diskord` с исходным кодом) нужна только для сборки.**
После установки всё, что нужно приложению для работы — сам `Discord.exe`,
его лог и кеш WebView2 — лежит в `Discord_v2` внутри `AppData\Local`. Всю
эту папку `diskord` можно удалить, Discord продолжит работать из
`AppData\Local\Discord_v2` (ярлык на рабочем столе не сломается).

Если позже захотите пересобрать (например, я пришлю новую версию
`discord_app.py`) — просто скопируйте новый файл в эту папку и запустите
`Установить Discord.bat` заново.


### Что для этого нужно на компьютере

- Windows 10/11.
- Python 3.9+ ([python.org](https://www.python.org/downloads/), при
  установке отметьте "Add python.exe to PATH"). Если Python не найден,
  скрипт сразу об этом скажет.
- Microsoft Edge WebView2 Runtime — почти наверняка уже стоит (входит в
  Windows 11 и ставится вместе с обновлениями Edge на Windows 10).

## Полное удаление приложения

Дважды кликните **`Очистить папку.vbs`** — она сама:

1. удаляет ярлык **Discord** с рабочего стола;
2. удаляет папку `%LOCALAPPDATA%\Discord_v2` целиком (сам установленный
   `Discord.exe` и его данные);
3. попутно убирает случайные файлы сборки в папке проекта (`build\`,
   `dist\`, `Discord.spec`, `diskord_error.log`), если они там есть.

Без окон и консоли, в конце — одно сообщение с итогом. Она **не трогает**
`discord_app.py`, `requirements.txt`, `icon.ico`, `README.md`,
`Установить Discord.bat`, `create_shortcut.ps1` — то есть саму папку
проекта не удаляет, только всё лишнее внутри неё плюс установленную копию
в AppData и ярлык. Чтобы поставить снова — просто запустите
`Установить Discord.bat`.

## Файлы в проекте

- `discord_app.py` — код приложения.
- `requirements.txt` — зависимости (`pywebview`, `pythonnet`).
- `Установить Discord.bat` — установка/сборка в `AppData\Local\Discord_v2`
  + ярлык на рабочем столе.
- `create_shortcut.ps1` — вызывается из .bat, создаёт ярлык (правильно
  определяет папку Desktop, даже если её переносит OneDrive; иконка
  берётся прямо из готового exe, а не из файла проекта).
- `Очистить папку.vbs` — разовая уборка файлов от старых версий проекта.
- `icon.ico` — иконка в корне проекта, встраивается в exe при сборке
  (раньше лежала в подпапке `icons\`, теперь общей папкой служит сам
  корень проекта).
